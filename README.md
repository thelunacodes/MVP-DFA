# MVP-DFA - *Awesome Store*

#### 1. Descrição

Interface de *e-commerce* desenvolvida em *HTML*, *CSS* e *JavaScript*, utilizando a biblioteca *React*. 

Esse projeto conta com:

*1.* Visualização de produtos carregados a partir de um arquivo *JSON*;

*2.* Layout responsivo para dispositivos móveis;

*3.* Navegação entre páginas usando *React Router*;

*4.* Página "404" para rotas inexistentes;

*5.* Componentização de interface.


#### 2. Pré-Requisitos

1. Uma IDE de sua escolha (exemplo: Visual Studio Code)
2. Git
3. Node.js

#### 3. Instalação 

**Passo 1 - Clone o repositório para sua máquina**

Em um terminal, execute os comandos:
 
    git clone https://github.com/thelunacodes/MVP-DFA.git

**Passo 2 - Navegue para a pasta do projeto**

    cd MVP-DFA

**Passo 3 - Instale as dependências do projeto**

    npm install

**Passo 4 - Inicie o servidor**

    npm run dev

Após a inicialização, acesse a URL exibida no terminal:

    http://localhost:<número de porta>

**Como o projeto é executado em um servidor de desenvolvimento local, ele só pode ser acessado pela sua máquina.**
